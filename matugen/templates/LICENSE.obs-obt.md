# obs.obt — Event Horizon OBS theme

`matugen/templates/obs.obt` is a color-modified derivative of the **Yami**
theme design shipped with OBS Studio:

- Original: https://github.com/obsproject/obs-studio/blob/master/frontend/data/themes/Yami.obt
- Design author: Warchamp7 (OBS Project)
- License of the original: GNU General Public License v2.0-or-later
  https://www.gnu.org/licenses/old-licenses/gpl-2.0.html

Only the theme's color palette was changed (replaced with Event Horizon
material colors at render time); the layout, spacing and styling are
inherited unchanged from the Yami base. Icons rendered by this theme are
OBS's own bundled assets referenced at runtime via the `theme:` search path
and are not redistributed.

This file is distributed under the same GPL-2.0-or-later license as the
Yami theme it derives from.
